# Foodie

Expo React Native recipe app with category browsing, recipe details, favorites, and personal recipe create/edit/delete. Favorites and personal recipes are saved locally with AsyncStorage.

## Import into Expo Snack

For Snack's **Import Git Repository** option, create a public GitHub repository with the **contents of this folder at the repository root** (`app/`, `assets/`, `package.json`, and the Expo config). Then paste that repository URL into Snack. This app does not need a backend or API keys.

## Run

Install the dependencies listed in `package.json`, then start Expo. Open the project with Expo Go or use the Expo web preview.
